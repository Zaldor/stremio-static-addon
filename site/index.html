Install in Stremio Edit this setup
Page updates are automatic: when Stremio refreshes a configured catalog, the add-on reads the current page. Use Test & preview output to inspect the metadata and stream responses before installing. Stremio's Configure control opens this editor for the installed setup; saving changed pages creates a new install link. Pages must be publicly reachable, and the video selector must find a direct playable video URL. This setup tool does not store your configuration on a server; the install URL contains it.

Use CSS selectors such as .video-card, .title, img, or video source. The preview shows the Stremio catalog metadata and checks sample stream URLs, including detail-page streams. This add-on returns the media URLs you configure; it does not copy your videos.
